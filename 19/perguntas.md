# 5. Qual é a diferença entre requisição e resposta HTTP?
- **Requisição HTTP**: mensagem enviada pelo cliente ao servidor para solicitar ou enviar informações.
- **Resposta HTTP**: mensagem devolvida pelo servidor, contendo um código de status HTTP e os dados solicitados.
